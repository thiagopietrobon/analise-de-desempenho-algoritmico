REFERÊNCIA

Quicksort em Python

Trecho de referência para estudar a lógica. A animação acima é instrumentada separadamente em JavaScript.

def quicksort(valores):
    if len(valores) <= 1:
        return valores

    pivo = valores[0]
    menores = [x for x in valores[1:] if x <= pivo]
    maiores = [x for x in valores[1:] if x > pivo]

    return quicksort(menores) + [pivo] + quicksort(maiores)

03 / GUIA DE INVESTIGAÇÃO

Como interpretar o que você vê

Use os resultados como evidência experimental, não como substituto da análise teórica.

Partições desequilibradas

Escolher o primeiro elemento como pivô pode gerar partições muito desiguais em entradas ordenadas, aproximando o comportamento do pior caso quadrático.

Escolha aleatória

Sortear o pivô reduz a dependência da ordem inicial, mas não elimina a possibilidade teórica de partições ruins.

Experimento ≠ prova

Os tempos dependem do navegador, do dispositivo e das condições de execução. A complexidade não deve ser concluída a partir de uma única medição.

Separação dos dados: o caderno de medições exibe os valores do CSV do projeto; a bancada usa entradas próprias e mede localmente. Não compare esses tempos como se tivessem sido obtidos no mesmo ambiente.
